# 台灣太陽能潛能分析

## 專案概述

本計畫分析台灣三大大城市的日照時長資料：

* 臺北

* 臺中

* 高雄

目標是透過分析不同城市、年份和月份的日照模式，評估**太陽能潛力**。

---

## 資料集

氣象資料來自台灣中央氣象局。

數據集包​​含：

* `stno`：氣象站 ID

* `yyyymm`：年份和月份

* `TX01`：平均溫度

* `SS01`：總日照時長（小時）

* `year`：年份

* `city`：城市名稱

## 分析內容

1. **城市日照時長排名**

比較台北、台中和高雄的平均日照時長。

2. **城市與年份比較**

分析 2024 年至 2025 年的日照趨勢。

3. **月度日照趨勢**

確定哪些月份的太陽能潛力最高。

4. **城市季節性模式**

比較不同城市各月的日照分佈。
