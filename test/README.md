# 太陽能資料分析測試（Testing）

本專案針對太陽能與氣象資料進行資料處理與分析，並設計測試流程以確保資料正確性與分析結果可靠。

## 測試內容

測試涵蓋以下項目：

- 資料缺失值檢查（Missing Value）
- 資料格式驗證（Format Validation）
- 異常數值檢測（Outlier Detection）
- 分析結果驗證（Data Accuracy）

## 測試方式

- 使用 Python（pandas）進行資料檢查
- 設計 Test Case 驗證資料處理流程
- 比對原始資料與分析結果

## 測試成果

- 發現資料來源格式不一致問題
- 發現部分資料存在缺失值與異常數值
- 修正資料後提升分析結果準確性
